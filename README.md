# Personal Portfolio Website

Welcome to the repository for my personal portfolio website, showcasing my projects, skills, and experiences as a developer. This site serves as a platform to highlight my work and share insights into my professional journey.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [Getting Started](#getting-started)
- [Inspiration](#inspiration)
- [License](#license)

## Features

- **Responsive Design**: Ensures optimal viewing experience across various devices.
- **Project Showcase**: Highlights selected projects with descriptions and links.
- **About Me**: Provides an overview of my background, skills, and interests.
- **Contact Form**: Allows visitors to get in touch directly through the website.

## Technologies Used

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Component Library**: [Shadcn](https://ui.shadcn.com/)
- **Monitoring**: [Sentry](https://sentry.io/welcome/)
- **Animations**: Implemented using CSS and JavaScript for interactive elements.

## Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**:

    ```bash
    git clone https://github.com/danmcgrath10/personal-website-2.git
    ```

2. **Navigate to the project directory**:

    ```bash
    cd personal-website-2
    ```

3. **Install dependencies**:

    ```bash
    npm install
    ```

4. **Start the development server**:

    ```bash
    npm run dev
    ```

5. **Open your browser** and visit `http://localhost:3000` to view the website.
